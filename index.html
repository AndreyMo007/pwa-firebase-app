// ====== ИСПРАВЛЕННАЯ PVP СИНХРОНИЗАЦИЯ ====== // Функция для проверки и удаления мёртвых юнитов function cleanupDeadUnits() { let hasDead = false; for (let r = 0; r < ROWS; r++) { for (let c = 0; c < COLS; c++) { const cell = grid[r]?.[c]; if (cell && cell.unit && cell.hp <= 0) { console.log(`💀 Очистка мёртвого юнита [${r},${c}]: ${cell.unit} HP=${cell.hp}`); cell.unit = null; cell.hp = 0; cell.maxHp = 0; cell.damage = 0; cell.attackRange = 0; cell.heal = 0; cell.cardData = null; cell.hasMovedThisRound = false; hasDead = true; } } } return hasDead; } // Сохранение поля с ПРЯМЫМИ данными о смерти function saveMyField() { if (!pvpRoom) return; // Сначала очищаем мёртвых cleanupDeadUnits(); // Сохраняем свои ряды (3-5) как есть const myUnitsData = []; for (let r = 3; r < 6; r++) { const rowData = []; for (let c = 0; c < COLS; c++) { const cell = grid[r][c]; rowData.push(cell.unit && cell.hp > 0 ? { u: cell.unit, h: cell.hp, mh: cell.maxHp, d: cell.damage, ar: cell.attackRange, heal: cell.heal || 0, hm: cell.hasMovedThisRound } : null); } myUnitsData.push(rowData); } // Сохраняем врагов (ряды 0-2) - ВАЖНО: сохраняем реальное состояние после моих атак const enemyUnitsData = []; for (let r = 0; r < 3; r++) { const rowData = []; for (let c = 0; c < COLS; c++) { const cell = grid[r][c]; // Сохраняем null если юнита нет или он мёртв rowData.push(cell.unit && cell.hp > 0 ? { u: cell.unit, h: cell.hp, mh: cell.maxHp, d: cell.damage, ar: cell.attackRange, heal: cell.heal || 0, alive: true } : null); } enemyUnitsData.push(rowData); } const saveData = { myUnits: myUnitsData, enemyUnits: enemyUnitsData, phase: gamePhase, elixir: elixir, timestamp: Date.now() }; console.log('💾 Сохранение поля:', saveData); set(ref(db, 'pvp_fields/' + pvpRoom + '/' + playerId), saveData); } // Отслеживание поля противника function watchOpponentField() { if (!pvpRoom || !pvpOpponentId) return; console.log('👀 Начинаю отслеживание поля противника:', pvpOpponentId); onValue(ref(db, 'pvp_fields/' + pvpRoom + '/' + pvpOpponentId), (snap) => { const data = snap.val(); if (!data) { console.log('❌ Нет данных от противника'); return; } console.log('📥 Получены данные противника:', data); // Обновляем врагов (ряды 0-2) из myUnits противника if (data.myUnits) { for (let r = 0; r < Math.min(3, data.myUnits.length); r++) { if (!data.myUnits[r]) continue; for (let c = 0; c < Math.min(COLS, data.myUnits[r].length); c++) { const myRow = 2 - r; const myCol = 3 - c; const unitData = data.myUnits[r][c]; if (!grid[myRow] || !grid[myRow][myCol]) continue; if (unitData && unitData.u && unitData.h > 0) { // Юнит жив - обновляем grid[myRow][myCol].unit = unitData.u; grid[myRow][myCol].hp = unitData.h; grid[myRow][myCol].maxHp = unitData.mh || unitData.h; grid[myRow][myCol].damage = unitData.d || 0; grid[myRow][myCol].attackRange = unitData.ar || 1; grid[myRow][myCol].heal = unitData.heal || 0; grid[myRow][myCol].hasMovedThisRound = unitData.hm || false; grid[myRow][myCol].cardData = ALL_CARDS.find(c => c.emoji === unitData.u) || null; console.log(`✅ Враг жив [${myRow},${myCol}]: ${unitData.u} HP=${unitData.h}`); } else { // Юнит мёртв или не существует - удаляем if (grid[myRow][myCol].unit) { console.log(`💀 Враг умер [${myRow},${myCol}]: ${grid[myRow][myCol].unit}`); } grid[myRow][myCol].unit = null; grid[myRow][myCol].hp = 0; grid[myRow][myCol].maxHp = 0; grid[myRow][myCol].damage = 0; grid[myRow][myCol].attackRange = 0; grid[myRow][myCol].heal = 0; grid[myRow][myCol].hasMovedThisRound = false; grid[myRow][myCol].cardData = null; } } } } // Обновляем HP своих юнитов из enemyUnits противника if (data.enemyUnits) { for (let r = 0; r < Math.min(3, data.enemyUnits.length); r++) { if (!data.enemyUnits[r]) continue; for (let c = 0; c < Math.min(COLS, data.enemyUnits[r].length); c++) { const myRow = 5 - r; const myCol = 3 - c; const enemyData = data.enemyUnits[r][c]; if (!grid[myRow] || !grid[myRow][myCol] || !grid[myRow][myCol].unit) continue; if (enemyData && enemyData.u && enemyData.h > 0) { // Наш юнит жив, но получил урон - обновляем HP const oldHp = grid[myRow][myCol].hp; grid[myRow][myCol].hp = enemyData.h; if (oldHp !== enemyData.h) { console.log(`💔 Наш юнит [${myRow},${myCol}] получил урон: ${oldHp} -> ${enemyData.h}`); } } else { // Наш юнит убит противником - удаляем console.log(`💀 Наш юнит убит [${myRow},${myCol}]: ${grid[myRow][myCol].unit}`); grid[myRow][myCol].unit = null; grid[myRow][myCol].hp = 0; grid[myRow][myCol].maxHp = 0; grid[myRow][myCol].damage = 0; grid[myRow][myCol].attackRange = 0; grid[myRow][myCol].heal = 0; grid[myRow][myCol].hasMovedThisRound = false; grid[myRow][myCol].cardData = null; } } } } // Синхронизация фазы if (data.phase && data.phase !== gamePhase) { gamePhase = data.phase; updatePhaseDisplay(); } if (data.elixir !== undefined) { elixir = data.elixir; updateElixirDisplay(); } // Очищаем мёртвых после обновления cleanupDeadUnits(); }); } // Улучшенная атака с немедленной проверкой смерти function unitAttack(row, col) { const cell = grid[row][col]; if (!cell || !cell.unit) return; console.log(`⚔️ Атака юнита [${row},${col}] с уроном ${cell.damage}, радиус ${cell.attackRange}`); const dir = row >= 3 ? -1 : 1; let targetsHit = 0; // Атакуем ВСЕ цели в области for (let r = 1; r <= cell.attackRange; r++) { const tr = row + dir * r; if (tr < 0 || tr >= ROWS) break; for (let c = Math.max(0, col - 1); c <= Math.min(COLS - 1, col + 1); c++) { const tc = grid[tr]?.[c]; if (!tc || !tc.unit) continue; const isEnemy = (row >= 3 && tr < 3) || (row < 3 && tr >= 3); if (!isEnemy) continue; // Наносим урон const actualDamage = cell.damage; tc.hp -= actualDamage; targetsHit++; console.log(`💥 Урон ${actualDamage} по врагу [${tr},${c}]! HP: ${tc.hp}/${tc.maxHp}`); highlightedCells.push({ row: tr, col: c, color: 'rgba(255, 40, 40, 0.8)', text: '-' + actualDamage }); // НЕМЕДЛЕННАЯ проверка смерти if (tc.hp <= 0) { console.log(`💀 Враг [${tr},${c}] уничтожен!`); tc.unit = null; tc.hp = 0; tc.maxHp = 0; tc.damage = 0; tc.attackRange = 0; tc.heal = 0; tc.cardData = null; } } } // Лечение союзников if (cell.heal > 0 && row >= 3) { for (let r = 1; r <= cell.attackRange; r++) { const tr = row + dir * r; if (tr < 0 || tr >= ROWS) break; for (let c = Math.max(0, col - 1); c <= Math.min(COLS - 1, col + 1); c++) { const tc = grid[tr]?.[c]; if (tc && tc.unit && tr >= 3) { const healAmount = cell.heal; const oldHp = tc.hp; tc.hp = Math.min(tc.maxHp, tc.hp + healAmount); const actualHeal = tc.hp - oldHp; if (actualHeal > 0) { console.log(`💚 Лечение [${tr},${c}] +${actualHeal} HP (${tc.hp}/${tc.maxHp})`); highlightedCells.push({ row: tr, col: c, color: 'rgba(50, 255, 100, 0.6)', text: '+' + actualHeal }); } } } } } // Сразу сохраняем в Firebase if (currentMode === 'pvp') { saveMyField(); syncAttack(row, col); } } // Вражеская атака с немедленной смертью function enemyAttack(row, col) { const cell = grid[row][col]; if (!cell || !cell.unit || cell.damage <= 0) return; console.log(`👾 Враг атакует из [${row},${col}]`); const dir = 1; let targetsHit = 0; for (let r = 1; r <= cell.attackRange; r++) { const tr = row + dir * r; if (tr < 0 || tr >= ROWS) break; for (let c = Math.max(0, col - 1); c <= Math.min(COLS - 1, col + 1); c++) { const tc = grid[tr]?.[c]; if (!tc || !tc.unit) continue; tc.hp -= cell.damage; targetsHit++; console.log(`💥 Враг нанёс ${cell.damage} урона по [${tr},${c}]! HP: ${tc.hp}/${tc.maxHp}`); highlightedCells.push({ row: tr, col: c, color: 'rgba(255, 40, 40, 0.8)', text: '-' + cell.damage }); // Немедленная смерть if (tc.hp <= 0) { console.log(`💀 Наш юнит [${tr},${c}] уничтожен!`); tc.unit = null; tc.hp = 0; tc.maxHp = 0; tc.damage = 0; tc.attackRange = 0; tc.heal = 0; tc.cardData = null; } } } // Сохраняем в PvP if (currentMode === 'pvp') { saveMyField(); } } // Добавляем очистку при получении данных противника в startPvP function startPvP() { document.getElementById('pvp-waiting').classList.add('active'); let resolved = false; const unsubSignal = onValue(ref(db, 'pvp_signals/' + playerId), (snap) => { if (resolved || pvpRoom) return; const sig = snap.val(); if (sig && sig.roomId) { resolved = true; pvpRoom = sig.roomId; pvpOpponentId = sig.hostId; pvpIsHost = false; remove(ref(db, 'pvp_signals/' + playerId)); remove(ref(db, 'pvp_queue/' + playerId)); unsubSignal(); initGrid(true); document.getElementById('pvp-waiting').classList.remove('active'); startGame(); // Даём время на инициализацию setTimeout(() => { cleanupDeadUnits(); saveMyField(); watchOpponentField(); watchGameState(); watchOpponentAttack(); }, 1000); } }); set(ref(db, 'pvp_queue/' + playerId), { playerId, time: Date.now() }); setTimeout(() => { if (resolved || pvpRoom) return; const unsubQueue = onValue(ref(db, 'pvp_queue'), (snap) => { if (resolved || pvpRoom) return; const data = snap.val(); if (!data) return; const others = Object.entries(data).filter(([key]) => key !== playerId); if (others.length > 0) { resolved = true; const [oppKey] = others[0]; pvpRoom = 'room_' + Date.now(); pvpOpponentId = oppKey; pvpIsHost = true; remove(ref(db, 'pvp_queue/' + playerId)); remove(ref(db, 'pvp_queue/' + oppKey)); unsubQueue(); initGrid(true); set(ref(db, 'pvp_signals/' + oppKey), { roomId: pvpRoom, hostId: playerId }); document.getElementById('pvp-waiting').classList.remove('active'); startGame(); setTimeout(() => { cleanupDeadUnits(); saveMyField(); watchOpponentField(); watchGameState(); watchOpponentAttack(); }, 1000); } }); }, 2000); setTimeout(() => { if (!resolved && document.getElementById('pvp-waiting').classList.contains('active')) { remove(ref(db, 'pvp_queue/' + playerId)); remove(ref(db, 'pvp_signals/' + playerId)); document.getElementById('pvp-waiting').classList.remove('active'); alert('Соперник не найден'); } }, 30000); } // Добавляем очистку мёртвых юнитов в startPlacementPhase function startPlacementPhase() { // Очищаем мёртвых перед новой фазой cleanupDeadUnits(); gamePhase = 'placement'; isPlayerTurn = false; elixir = Math.min(MAX_ELIXIR, elixir + 5); selectedUnitRow = -1; selectedUnitCol = -1; highlightedCells = []; placementHighlights = []; enemyActionHighlights = []; updateElixirDisplay(); updatePhaseDisplay(); // Сбрасываем флаги движения for (let r = 0; r < ROWS; r++) { for (let c = 0; c < COLS; c++) { if (grid[r] && grid[r][c]) { grid[r][c].hasMovedThisRound = false; } } } availableCards = shuffleArray(ALL_CARDS).slice(0, 5); purchasedCards = []; selectedPurchasedCard = null; renderCards(); timerSeconds = 20; document.getElementById('game-timer').textContent = timerSeconds; if (timerInterval) clearInterval(timerInterval); timerInterval = setInterval(() => { timerSeconds--; document.getElementById('game-timer').textContent = timerSeconds; if (timerSeconds <= 0) { clearInterval(timerInterval); startBattlePhase(); } }, 1000); if (currentMode === 'pvp') { saveMyField(); syncStateToFB(); } } // Добавляем очистку в processTurn function processTurn() { // Очищаем мёртвых перед проверкой ходов cleanupDeadUnits(); const { playerMoves, enemyMoves } = checkMoves(); console.log(`🔄 Ходов: игрок=${playerMoves}, враг=${enemyMoves}`); if (playerMoves === 0 || enemyMoves === 0) { console.log('🔄 Новая фаза расстановки');
